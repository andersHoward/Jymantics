JYMANTICS is a local-first simulation tool for designing and simulating system
models, economies, state machines, etc.
 
Diagrams are plain JSON files with a matching human-readable text format, 
so they're easy to version, compare and share. You can also export any diagram
as a standalone, play-only HTML page with adjustable values for clients or 
teammates.

Jymantics runs in any modern browser on Mac and Windows with nothing to
install, and comes with a command-line tool and a Claude extension, so
Claude can build, check and run models for you.
